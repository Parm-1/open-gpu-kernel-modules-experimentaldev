# DECISION-0004: Nova is a secondary track

Status: Accepted — 2026-08-17

## Decision

Use NVIDIA's shipping open-module/NVKMS stack for the first HDCP proof. Track Nova as the eventual upstream-native implementation target without delaying the initial experiment.

## Reason

The shipping stack contains a newly public HDCP reference implementation. Nova can benefit from a measured semantic map after the first path is understood.
