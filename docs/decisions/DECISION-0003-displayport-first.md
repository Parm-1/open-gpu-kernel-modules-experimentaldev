# DECISION-0003: DisplayPort SST first

Status: Accepted — 2026-08-17

## Decision

Initial runtime experiments use one direct DisplayPort SST route at SDR 1920×1080 60 Hz. HDMI, MST, adapters, docks, cloning, HDR, and VRR are excluded.

## Reason

The strongest public source evidence is in the DisplayPort library. Simplifying topology reduces ambiguous failures and makes negative controls meaningful.
